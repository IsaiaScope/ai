`★ Insight ─────────────────────────────────────`
- The recurring shape: **liveness detected by side-channel proxies** (pane scrollback text, /tmp checksums, output length) instead of authoritative state. Each proxy has a failure mode where "can't tell" defaults to the wrong answer — and the safe default flipped: "no pane → active" should arguably be "no pane → dead".
- **Unit ambiguity at a boundary** (`wait_seconds` 10000 threshold) is the classic heuristic-papering-over-inconsistent-callers smell — deliver.sh feeds ms, drive.sh feeds seconds into one `--timeout`. The deeper fix is one unit at the call site, not a guess in the callee.
